# dotfiles
The dotfiles I use to configure my environment. Changes semi-frequently.

# Tools List

- Bash
- Tmux
- Vim
- Taskwarrior/Timewarrior

## .bashrc

### Key ideas:

* Grab any global configs
* Set a custom path 
* Set up my custom aliases 
* Automatically attach to any Tmux sessions, or create a new one if there isn't one
* Use Vim-style input (rather than default Emacs style)
* Set my custom prompt

## .tmux.conf

### Key ideas:

* Make it "vim-like" with keybindings and motions
* Start indexing with 0 instead of 1
* Turn on mouse support by default
* Use the bash prompt
* Making the colors pretty
* Setting a time/date in the corner

## .vimrc

### Key ideas:

* Set the Airline theme when it is available
* Turn filetype and indentation plugins on
* Use syntax highlighting
* Use relative number highlighting
* Use autocompletion with wildmenu

_(Latest project)_
